# 2.8. Actividad con Sass

# Objetivo
Implementar la página principal (landing) del ejercicio anterior, esta vez usando sass.



# Organización y entrega
**Práctica individual.** Retomamos el repo anterior y hacemos una rama "sass". En dicha rama, se espera entregar la misma landing, precompilando el scss con sass a un css normal.





# Fase 1: Rehacer la landing con Sass
**Rehacer la misma landing**, usando **Sass** y utilizando como mínimo: **mixins, funciones y funciones nativas**. Si para hacer esto tenéis que añadir alguna feature adicional, o midificar la landing anterior, no hay problema.



# Fase 2: Compilación y deploy
Una vez tengáis todo listo, compilad el scss en un css nativo (también podéis usar plugins y configurar vuestro ide para que detecto los cambios en el scss y lo precompile automáticamente).

Una vez compilado, hace uso de las github pages de vuestro repo para que apunte a la rama "scss". **A ver qué tal se ve online!**
